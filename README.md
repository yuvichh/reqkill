# ReqKill : Chrome Extension

Basic instructions to load this extension into Chrome (developer / local install).

Prerequisites
- Google Chrome
- A GitHub account to fork the repo

Quick steps

1. Fork the repository on GitHub.
2. Clone your fork to your machine:

   git clone (https://github.com/yuvichh/reqkill)

3. Open Chrome and go to chrome://extensions
4. Turn on "Developer mode" (toggle at top-right).
5. Click "Load unpacked".
6. In the file dialog select the folder you cloned 
   - If the extension files live in a subfolder named `extension` or similar, select that folder instead.
7. The extension will appear in the extensions list. Pin or click its icon to open it.
8. After making changes locally, reopen chrome://extensions and click the Reload button on the extension card to apply updates.

Notes
- If you see an error after loading, check the extension card for diagnostics and fix any reported issues.

That's it the extension is loaded and ready to run locally.
